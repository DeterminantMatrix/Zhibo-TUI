# Zhibo Qt Quick / QML 原生界面

这是项目唯一的原生前端，直接复用项目根目录的监控与插件后端。

## 启动

首次使用先安装 Qt 运行依赖：

```powershell
.venv\Scripts\python.exe -m pip install -r qt_quick\requirements-qt.txt
```

双击 `qt_quick\start_native.vbs`，通过 `pythonw.exe` 启动，不依赖 Windows Terminal。

也可以运行：

```powershell
.venv\Scripts\python.exe -m qt_quick
```

## 当前功能

已接通以下功能：

- 监控表格、标签分组、搜索和在线/离线/异常筛选；
- 状态机、平台健康度、最近事件和安全脱敏详情；
- 原生系统托盘、最小化隐藏、通知开关和手动刷新；
- 关注项编辑、监控设置和直播间导入，均采用预览、确认和原子写入；
- 打开网页、复制流、复制选中、mpv 播放和停止播放；
- streamlink、streamget、yt-dlp、FS1 与 B站 Cookie 更新；
- YouTube 格式读取、画质选择、下载进度；
- Twitch、YouTube、Kick、CHZZK、TikTok 和 TwitCasting 独立代理设置。

底部功能键条保留通知、刷新、详情、编辑、设置、网页、复制流、导入、更新、下载、代理、筛选、托盘和退出。“复制选中”入口移到直播间右键菜单，`C` 与 `Ctrl+Shift+C` 快捷键仍然可用。

在表格中右键直播间，会先选中当前行，再显示修改直播间信息、状态详情、**停止/恢复监控**（立即生效，无需编辑确认）、播放/停止、复制直播流、复制直播间摘要、打开网页和下载当前视频等操作。

常用桌面交互约定：

- **双击行 = 播放**（画质列除外）；单击选中，右键弹菜单
- **点表头排序**：同列再点切换升降序，列头显示 ▲/▼；任何排序下在线主播始终排在前面，选择会记住
- **`Ctrl+F` 聚焦搜索**，`F5` 手动刷新
- 编辑/设置/导入的确认页点“返回”会**回到表单并保留已输入内容**，不会丢失
- 窗口大小、位置和最大化状态会自动记住，下次启动恢复
- 控件样式使用 Qt 官方 FluentWinUI3（Windows 11 原生风格）

功能键条固定在窗口底部；宽屏使用单行，窄屏会自动换成两行，所有按键都会保留并保持可点击。

额外键盘操作：`Enter` 播放、`X` 停止播放、`J` 导入、方向键切换选中行、`Esc` 关闭详情。
